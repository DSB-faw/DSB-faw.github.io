# Deepak Singh Bhadoriya — Portfolio

Personal portfolio site, built as a single self-contained `index.html` (no build step, no external dependencies) and hosted on GitHub Pages.

**Live:** https://dsb-faw.github.io/

## What's here

- `index.html` — the site itself. Dark, data/analytics-themed design with a scroll-driven "story" told from the résumé: Zomato (2019–2021) → IIM Lucknow (2022) → Cars24 (2021–present), animated KPI counters, a hand-built funnel visualization, and a categorized skills grid. Pure HTML/CSS/vanilla JS — no frameworks, no CDNs.
- `Deepak_Bhadoriya_Resume.pdf` — downloadable résumé, linked from the hero section.

## Local preview

```
python3 -m http.server 8000
```
then open `http://localhost:8000`.
